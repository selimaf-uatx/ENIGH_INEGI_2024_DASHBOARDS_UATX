ENIGH 2024 Data Modeling & Business Intelligence Dashboards made by UATx Students

## 📌 Project Overview
This repository hosts a collaborative data engineering and Business Intelligence (BI) project based on the **National Survey of Household Income and Expenditure (ENIGH) 2024**, published by Mexico's National Institute of Statistics and Geography ([INEGI](https://www.inegi.org.mx/programas/enigh/nc/2024/)).

The primary goal of this initiative is to transform raw, unstructured matrix-style INEGI tabulations into normalized relational data structures (*Tidy Data*). These processed datasets serve as the backend for interactive dashboards built in **Looker Studio**, enabling granular socioeconomic, demographic, and financial analysis across Mexican states.
